    Training a Transformer: An Interactive Simulation

    One training run of a tiny GPT, from raw text to generated text, one operation per slide:

    • a BPE tokenizer, embeddings, two transformer blocks (attention and MLP), the output layer and the loss;
    • the backward pass rule by rule, the AdamW update, 600 training steps, when to stop;
    • decoding with temperature and top‑p.

    Every number on the slides comes from tiny_gpt.py, a 300-line PyTorch script built on nanoGPT. The code box shows the lines behind each slide; the lamp (“More”) adds the why, alternatives, costs and further reading.
